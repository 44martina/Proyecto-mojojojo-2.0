Área de Desempeño Profesional

La especialidad se enfoca en el diseño, implementación, configuración y mantenimiento de infraestructuras de redes de datos locales (LAN) y extendidas (WAN). Los estudiantes desarrollan competencias clave en la administración de dispositivos activos de red, la implementación de políticas de seguridad informática y la gestión de sistemas operativos de servidor para garantizar la disponibilidad y optimización de los recursos tecnológicos.

Módulos Técnicos Obligatorios:

🖥️

Enrutamiento y Conmutación

Configuración lógica de protocolos de enrutamiento y administración de switches de capa 2 y capa 3 mediante CLI.

🔒

Seguridad en Redes

Implementación de listas de control de acceso (ACL), seguridad de puertos (Port Security) y firewalls perimetrales.

🐍

Automatización de Redes

Desarrollo de scripts funcionales para la optimización de tareas administrativas y gestión de redes basadas en software.

🗄️

Sistemas Operativos de Servidor

Instalación, despliegue de servicios esenciales (DHCP, DNS, Active Directory) y asignación de permisos NTFS.

Fundamentos Teóricos de la Especialidad

Marcos regulatorios y protocolos estándar esenciales en telecomunicaciones.

El Modelo de Referencia OSI

Estructura conceptual de siete capas que estandariza las funciones de abstracción de los protocolos de red:

7 Aplicación (HTTP, FTP, DNS, SSH)
6 Presentación (Cifrado, Sintaxis, Formatos)
5 Sesión (Control y mantenimiento del diálogo)
4 Transporte (Segmentación - TCP / UDP)
3 Red (Enrutamiento lógico y Direcciones IP)
2 Enlace de Datos (Direccionamiento Físico MAC / Switches)
1 Física (Transmisión binaria, Cables UTP, Fibra Óptica, Señales)

Direccionamiento Lógico e Infraestructura IP

Esquemas de direccionamiento indispensables para la localización de nodos dentro de una topología de red.

Métrica IPv4 IPv6
Longitud de Bits 32 bits (Estructura decimal de 4 octetos) 128 bits (Estructura hexadecimal de 8 segmentos)
Ejemplo de Host 192.168.10.1 2001:db8:acad::1
Disponibilidad ~4.3 millones de direcciones (Agotamiento global) Suficiente para asignar subredes masivas (340 sextillones)
Máscara de Subred: Máscara de bits que determina el prefijo de red y el espacio asignable para hosts de manera de segmentar dominios de difusión (Broadcast).
